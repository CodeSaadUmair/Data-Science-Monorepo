# Spam Email Classifier (Naive Bayes)

This project is a **Spam vs Ham email classifier** built using the **Multinomial Naive Bayes algorithm**.

## Features
- Train model using email dataset
- Classify emails as **Spam** or **Ham**
- User input support for testing new emails
- Accuracy and classification report included

## Ensure you have the dataset file:
spam_ham_dataset.csv

## Interaction:
Model Accuracy: 0.98

Enter an email text (or type 'exit' to quit): Congratulations! You have won $1000 cash.
Prediction: Spam
